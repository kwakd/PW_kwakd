entry #6: glhf-grow-desktop-journalapp

february-2026 [week 3]

The project is officially done and released 🎉 There's still some cleanup to do on the website side of things—I had a lot of sections to update, and it's not fully finished yet—but in terms of the game itself, it's officially in v1. That alone feels surreal to say. I definitely want to keep building on it, add more content, and eventually work on an Android version with the goal of releasing it properly on an app store at some point. That's more of a long-term plan, but it's something I really want to pursue once things settle.

One of the main reasons the release was slightly delayed was because I wanted to work on a Mac version as well. Unfortunately, newer macOS versions have stricter permission systems, and I ran into issues with third-party developer apps not being allowed to open properly. There's probably a workaround for it, but I don't currently have a Mac device to properly test and debug it. Theoretically, the build should work on Macs, but this is something I'll have to officially fix and support later on.

For now though, the project is officially uploaded on itch.io 🚀 That alone feels like a massive milestone.

With this project now in a released state, I'm finally moving on to the next chapter—either starting an official multiplayer game (most likely my rendition of a quick-chess concept) or jumping into a small 3D platformer project. Realistically, I think the chess-style multiplayer game is the direction I'll go, but I'll see how things feel once I start prototyping.

Either way, it feels really good to finally close this chapter. Even if it's not "done forever," this project is officially complete in its first real version—and that alone is a huge win. Just excited to move forward and start building something new. 🔥

If anyone has any ideas for this project or design suggestions they'd like to see implemented, feel free to let me know! I've also included the PSD file for the default character and the PSD file for the H-character for anyone who wants to experiment with designs or contribute concepts.

If you create anything or have suggestions, please email them to kwakd804@gmail.com — I'd love to see what people come up with!

february-2026 [week 1-2]

This week was mostly focused on drawing and finishing touches, which was honestly really exciting. During the first two weeks of February, the main focus was creating the final character assets and making sure everything in the project was functioning properly. Because of that, most of this week was dedicated to designing the epic-tier assets and implementing them into the game. It felt really satisfying to finally see these higher-tier designs come together and actually work in-game instead of just existing as concepts.

The following day, I moved on to working on the legendary-tier assets, which took a bit longer than expected. These required separate actions and unique behaviors, so there was more setup and testing involved compared to the other tiers. Even so, once those were finished and fully implemented, it finally felt like everything clicked into place.

At this point, the base of the game is officially done. All that's left now is testing, polishing, and making sure everything feels stable and consistent before release. It honestly feels surreal being this close to the finish line—after all the planning, building, and iteration, the project is finally in its final phase. The release is now within reach, and it's exciting to see everything coming together at last.
