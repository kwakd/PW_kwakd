glhf - grow - desktop - journalapp

about this project:

This project began as a personal prototype inspired by my interest in journaling and interactive design. The goal was to explore a more engaging way to record daily experiences by turning traditional journal entries into something visual, collectible, and game-like.

The core idea is simple: once per day, users can create a “moment”—a small generated character that represents that day’s journal entry. Each character functions as both a visual memory marker and an interactive object. Users can open an entry to write freely, add personal reflections, and upload an image, turning each moment into a personalized snapshot of the day. All data is currently stored locally, as this project is still in a prototype stage and focused on experimentation rather than long-term infrastructure.

The system uses a rarity model to introduce variation and progression, with characters generated as Common, Epic, or Legendary. This adds a light collectible layer while still keeping the focus on journaling and personal expression rather than progression mechanics.

At its core, this project is an experiment in blending game design principles with reflective journaling, exploring how interactivity, visual identity, and simple systems can make personal documentation more engaging. It’s an evolving prototype, and future plans include a mobile version, expanded content, and continued refinement of the interaction systems.
