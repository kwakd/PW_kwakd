This is my first post for the blog. My goal here is to share progress on my personal projects and keep myself accountable by regularly documenting updates. I may occasionally touch on personal life topics, but the main focus will be tracking my development work. This entry will be a bit longer than usual since I’ll also be introducing the app I’m currently working on: glhf-grow.

Week of August 9th

For the week of August 9th, I focused on building the initial foundations for glhf-grow, an Android application designed to help people stay distraction-free from their phones. The app will feature a character that also acts as a journal entry—users can rename the character and add text to write about anything they like. I’m still deciding whether to use Unity’s built-in text box (which currently has a limit of around 512 characters) or implement a custom solution to allow longer journal entries.

The main objectives for this project are to learn how Unity functions with Android, create a basic app for the Play Store, and gain experience with Android development. If possible, I’d also like to create an iOS version and a simple web version for the project’s website, though those will depend on time and feasibility.

This week’s work was centered on a few core features:
  • Implemented a basic save system for each character, something I missed in my last project. I wanted to handle this early to avoid future roadblocks, and a YouTube tutorial helped me get it running smoothly.
  • Added randomized character names.
  • Started work on skin variations, including rare “shiny” variants that may feature unique visual effects like trails.
  • Created a basic placeholder character with simple roaming behavior.
Next, I plan to add animations for the base character, reintroduce special animations for legendary-tier characters, and build a menu for viewing all collected characters along with their details.
