entry #10: journal-platform

july-2026 [early]

Took the journal app out of its Claude artifact sandbox and turned it into a real, standalone codebase — React + Vite, with personal entries now persisted locally through IndexedDB instead of the artifact's window.storage. The bigger lift was rebuilding Party (the shared/social side) on actual infrastructure: Supabase Postgres with real Row Level Security instead of an insecure shared key-value store that had no querying and no access control at all.

Most of this stretch went into a moderation system built from scratch. Anyone can report a post, a comment, or someone's profile photo, and once something collects three independent reports it gets hidden automatically — reported posts drop out of the feed, reported comments get censored in place pending review, and a reported profile photo blanks out to a shape-only wisp everywhere that person shows up. The reporter also sees their own report take effect immediately, before the threshold even hits. There's no automated content filtering behind any of this yet — no blocklist, no vision API, review still happens by hand in the Supabase dashboard — but at least abusive content doesn't sit in the feed waiting on a human to notice it.

july-2026 [later]

Spent the next stretch hardening what I'd just built instead of adding more on top of it. Closed the one write path that wasn't rate-limited yet (likes), and fixed a shadowing bug in the RLS policies that had accidentally broken replies on hidden posts.

On the account side, I built out Back up / Restore for syncing personal entries across devices — deliberately dumb rather than clever, since silent sync bugs are the kind of thing I did not want to debug later. Backup is just an idempotent upsert you can hit as many times as you want; restore only fills in dates you don't already have unsynced local changes for, so it merges instead of quietly overwriting anything. Fixed a bug where one oversized entry could block an entire backup from going through, and added a proper confirmation-email notice on account creation so that part isn't a silent no-op either.

Closed the whole stretch out by fixing a couple of stale claims in the README and adding a CLAUDE.md so the project's conventions and gotchas are actually written down somewhere instead of just living in my head. It's deployable now — any static host works off a plain npm run build — though content moderation staying report-driven instead of automated is still the most obvious gap if this ever needs to hold up to real traffic.
