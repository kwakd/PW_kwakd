glhf - capsule v0.5

how to play

Each character costs $100 and belongs to one of four tiers; higher tiers earn more passive income. The goal is to buy THE KING. You can also sell characters or rename them. In the sell menu, green text is what a character earns per cycle and what you get for selling it; red text is how many seconds it takes to earn. That is the whole loop — watch your characters roam, earn, buy more, work toward the final one. A lot of planned content was cut for this version.

- THERE IS NO SAVE STATE FOR THIS GAME
- Game can only be played on 700px or wider (No Mobile)

about: glhf - capsule v0.5

This came out of an interest in idle games, particularly Gnorp Apologue and Tower Wizard. I wanted something simple, focused on collecting characters. What exists is a bare-bones prototype — a version 0.5. During development I hit a wall: a key feature I could not get in early would have meant rebuilding the whole system to add later, so several planned features got cut. I learned a lot from that, and the shape of the full project is much clearer now.

For future versions I want to add NFC tags, so you unlock characters by scanning physical keychains — small 3D models I would print myself, linking real collectibles to in-game content. Before version 1 there are a few other things I want to finish: a small app that hooks into Steam inventory for item drops, a study app for staying off your phone, and a basic 3D platformer to start learning 3D properly. Balancing work and development time is hard, but I will post progress here as I go.
